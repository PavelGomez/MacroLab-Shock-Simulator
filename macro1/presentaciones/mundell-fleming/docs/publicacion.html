Publicar y compartir el aula

La entrega está preparada para subirla como un sitio estático: HTML, JavaScript, estilos y siete MP3 locales. No necesita servidor de aplicaciones ni herramientas de producción. Esta guía no crea una dirección pública; esa dirección la proporciona el portal o el alojamiento que elijas.

Archivo que debes usar: COMPARTIR_Mundell_Fleming_Macro1.zip, aproximadamente 21 MB. Al extraerlo encontrarás PRESENTACION_MUNDELL_FLEMING/index.html. Conserva la estructura de carpetas completa.

En el portal del curso

Si el portal permite publicar un conjunto de archivos HTML, sube el paquete como recurso web y selecciona index.html como entrada. Adjuntar el ZIP sin extraerlo sirve para que los estudiantes descarguen el aula y estudien sin conexión.

Si usas Moodle:

  1. Activa la edición del curso y agrega un recurso Archivo. Nómbralo «IS–LM abierto: aula narrada de Mundell–Fleming».
  2. Sube el ZIP. En el administrador de archivos del recurso, selecciónalo y elige Descomprimir.
  3. Entra en la carpeta extraída, selecciona index.html y elige Establecer como archivo principal.
  4. En Apariencia, usa Abrir o Nueva ventana, si está disponible, para dar espacio a la presentación. Guarda y muestra el recurso.
  5. Comparte el enlace del recurso del curso. El estudiante ingresará con su cuenta institucional.

Procedimiento basado en la documentación oficial de Moodle: archivos y páginas web, consultada el 1 de noviembre de 2026. Los nombres de las opciones dependen de la traducción y configuración institucional.

Si el portal descarga el HTML en vez de ejecutarlo, o restringe JavaScript, usa alojamiento web y agrega su dirección como recurso URL. Pegar el contenido de index.html en el editor de texto del portal no conserva el aula. Si el límite de carga es inferior al tamaño del ZIP, el administrador debe ampliarlo o debes usar la opción de enlace web.

Un enlace web para el portal y el correo

Un servidor web institucional puede alojar la carpeta completa y entregarte una URL HTTPS. Solicita que index.html sea la entrada y que se mantengan las rutas relativas a assets/ y docs/. Para enlaces enviados por correo, esta es la alternativa que permite abrir el aula directamente.

También puedes usar GitHub Pages:

  1. Crea un repositorio, por ejemplo mundell-fleming-macro1. Con GitHub Free, el repositorio debe ser público; el sitio quedará accesible en internet.
  2. Sube el contenido de la carpeta extraída, conservando subcarpetas. index.html debe quedar en la raíz del repositorio. Incluye el archivo vacío .nojekyll. Subir solo el ZIP no publica la presentación.
  3. Abre Settings → Pages → Deploy from a branch. Elige la rama main y /(root); guarda.
  4. Cuando finalice la publicación, copia la dirección que aparece en Visit site. Usa esa misma dirección en el portal y en el correo.

Fuentes: crear un sitio en GitHub Pages y configurar la fuente de publicación, consultadas el 1 de noviembre de 2026.

Al subir la versión definitiva

Comprueba con la vista de estudiante que se escucha el audio, avanza la diapositiva 13, abre «Ver interceptos» y vuelve al mismo instante. Si el aula ya estaba abierta, recarga la pestaña para recibir esta revisión. Las hojas de estilos y los scripts llevan versión de caché 4; los MP3 conservan la voz y los tiempos aprobados.

El progreso se guarda en el navegador y equipo usados cuando está permitido. No se sincroniza entre dispositivos ni se envían respuestas o calificaciones al portal. La entrega no es un paquete SCORM. Para estudiar sin conexión, distribuye el ZIP y pide extraerlo antes de abrir index.html.

La verificación realizada incluye modelo y controles con DOM/audio simulados y composición estática en tres tamaños. La prueba multimedia en el portal y navegadores de destino sigue pendiente: el entorno de revisión bloqueó el acceso local del navegador. Registro de comprobaciones y límites.
