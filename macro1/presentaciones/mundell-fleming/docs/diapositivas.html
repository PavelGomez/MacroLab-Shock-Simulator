Desarrollo completo

La pregunta económica

  1. Compras públicas aumentan.
  2. La empresa vende al exterior y compra maquinaria importada.
  3. ¿Basta el multiplicador de una economía cerrada?

Dos reglas para el mismo impulso

  1. Flotación: el precio del dólar puede ajustar.
  2. Cambio fijo: la autoridad defiende una paridad.
  3. Antes de conocer el resultado, predice si la producción cambia igual.

Qué podrás resolver

  1. Calcular un equilibrio abierto.
  2. Comparar la misma política bajo ambos regímenes.
  3. Explicar el resultado y los supuestos que lo sostienen.

EL PUENTE DESDE IS–LM CERRADO

La demanda por producción nacional

C + I + G+ X − IM
Z = C + I + G + XN

Z define demanda planeada por producción nacional.

Y = Z

Equilibrio: sin inventarios involuntarios.

C: consumo; I: inversión; G: compras públicas. IM se resta porque parte del gasto ya incluye producción importada.

VER EL RAZONAMIENTO

Paso a paso

Desarrollo completo

Pasar del gasto total a producción nacional

  1. Gasto de residentes: C + I + G
  2. Agregar ventas a no residentes: + X
  3. Restar producción extranjera incluida en el gasto: − IM

Separar definición y equilibrio

  1. Definición: XN = X − IM
  2. Definición: Z = C + I + G + XN
  3. Equilibrio de bienes: Y = Z

Fuera del equilibrio pueden aparecer inventarios involuntarios.

Conservar las funciones de conducta

  1. C = c0 + c1(Y − T)
  2. I = b0 + b1Y − b2i
  3. T: impuestos fijos; c1: fracción consumida del ingreso disponible.
  4. b1: respuesta de inversión a Y; b2: respuesta por punto porcentual de i.
  5. i = 4 representa 4 % anual.

Capítulo 2Diapositiva 6

DERIVACIÓN

Construir la IS abierta, paso a paso

A = c0 − c1T + b0 + G + x0

A mayúscula: gasto autónomo, como en las clases previas.

a = 1 − c1 − b1 + x1; α = 1/a

a minúscula: coeficiente de Y. α: multiplicador parcial de bienes.

aY = A − b2i + x2E

VER EL RAZONAMIENTO

Paso a paso

Desarrollo completo

Sustituir y distribuir

  1. Y = c0 + c1(Y − T) + b0 + b1Y − b2i + G + x0 − x1Y + x2E
  2. c1(Y − T) = c1Y − c1T
  3. Y = c0 + c1Y − c1T + b0 + b1Y − b2i + G + x0 − x1Y + x2E

Reunir Y y mantener la notación del curso

  1. Restar c1Y y b1Y; sumar x1Y en ambos lados.
  2. (1 − c1 − b1 + x1)Y = c0 − c1T + b0 + G + x0 − b2i + x2E
  3. a = 1 − c1 − b1 + x1
  4. A = c0 − c1T + b0 + G + x0

A mayúscula sigue representando gasto autónomo. a minúscula es un coeficiente distinto.

Dividir todos los términos por a

  1. aY = A − b2i + x2E
  2. (aY)/a = A/a − (b2/a)i + (x2/a)E
  3. Y = (A − b2i + x2E)/a
  4. α = 1/a = ∂Y/∂G, con i y E dados.

a es el inverso del multiplicador parcial α; A es el gasto autónomo.

UNA CONDICIÓN, NO UNA IDENTIDAD

La condición externa: BP horizontal

i = i* = 4 %
BP horizontalXN puede ser negativo

Sin prima ni depreciación esperada. No es la identidad de toda la balanza de pagos.

VER EL RAZONAMIENTO

Paso a paso

Desarrollo completo

Declarar el arbitraje

  1. Economía pequeña: la tasa externa se toma como dada.
  2. Activos comparables y movilidad perfecta de capitales.
  3. Un diferencial de rendimientos genera presión para cambiar la cartera.

Obtener la condición simplificada

  1. Prima por riesgo = 0
  2. Depreciación esperada = 0
  3. BP: i = i*
  4. Ambas tasas se expresan en % anual y para el mismo horizonte.

No confundir dos condiciones

  1. i = i* no implica XN = 0.
  2. Un déficit de bienes y servicios puede coexistir con financiamiento externo.
  3. BP horizontal no es la identidad contable de toda la balanza de pagos.

ANTES DE CALCULAR

El régimen decide qué variable ajusta

M/P = Md = d1Y − d2i
Precios, parámetros y tasa externa dados en ambos regímenes.
RégimenDadoAjustaOrden para resolver
FlotaciónM/PEBP → LM → IS
FijoEM/PBP → IS → LM

LM como Y = F(i)

Y = (M/P)/d₁ + (d₂/d₁)i

VER EL RAZONAMIENTO

Paso a paso

Desarrollo completo

Despejar LM sin saltar operaciones

  1. M/P = d1Y − d2i
  2. Sumar d2i: M/P + d2i = d1Y
  3. Dividir por d1 > 0: Y = (M/P + d2i)/d1
  4. Recta LM: Y = (M/P)/d1 + (d2/d1)i
  5. M/P: oferta real de dinero; d1 y d2: coeficientes positivos.

Resolver bajo flotación

  1. Dato de política: M/P
  2. 1. BP entrega i = i*.
  3. 2. LM entrega Y = (M/P + d2i*)/d1.
  4. 3. IS entrega E = (aY − A + b2i*)/x2.

Orden algebraico de relaciones simultáneas; no es un reloj de ajuste.

Resolver bajo cambio fijo

  1. Dato de política: E
  2. 1. BP entrega i = i*.
  3. 2. IS entrega Y = (A − b2i* + x2E)/a.
  4. 3. LM entrega M/P = d1Y − d2i*.

El dinero acomoda la defensa de la paridad.
