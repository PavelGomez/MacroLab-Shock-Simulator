# Auditoría de alineación del recorrido · MacroLab 0.6.2

Fecha: 5 de agosto de 2026.

## Regla aplicada

Una caja sólo puede decir «ya sabes», «recuerda» o «recupera» cuando existe evidencia visible de una exposición anterior: texto presentado dentro del mismo recorrido, respuesta previa conservada o memoria importada. Completar un paso no autoriza a atribuir conceptos que ese paso no trabajó.

Cuando no existe esa evidencia, MacroLab usa una de estas formulaciones:

- «lo que acabas de hacer», para describir una acción realmente completada;
- «lo que se introduce ahora», para contenido nuevo;
- «la lectura presentó», para reconocer exposición sin afirmar dominio;
- «punto de partida cotidiano», cuando el ejemplo apela a experiencia general y no a teoría estudiada.

## Casos conservados

Se mantuvo lenguaje de recuperación cuando la evidencia sí existe: memoria importada, regla escrita en un intento anterior y comparación con una respuesta inicial visible. En esos casos la interfaz identifica el origen de la memoria.

## Criterio para cambios futuros

Toda nueva caja de transición debe responder tres preguntas:

1. ¿Qué acción o contenido apareció realmente antes?
2. ¿Qué se introduce por primera vez aquí?
3. ¿Qué tarea concreta viene después?

Si la primera pregunta no puede señalar una evidencia visible, la interfaz no debe hablar de conocimiento previo.
